Getting started

Which games do I need?

You need KOTOR, KOTOR II and Jedi Academy, all three installed. kjk uses KOTOR's and KOTOR II's worlds and stories, KOTOR II's interface and Jedi Academy's combat animations.

Copies from Steam and GOG are found automatically. kjk includes no game files, so you need your own copies.

How do I install kjk?

Download the kjk launcher from the home page and unpack it. Open the launcher and press Play. The launcher finds your games, downloads the newest version of kjk and keeps it up to date.

You can also download kjk itself from the GitHub releases page. Pick the file for your computer, not "Source code". The source code has no program in it. You don't need the SHA256SUMS file to play. It only checks that the download is not damaged.

Do my games have to be clean installs?

A clean install is the safest choice. Some mods break character creation, the interface or story scenes. If something looks broken, test the game without mods first.

To keep your mods for the original game, copy the game folder. Remove the Override folder from the copy, and point kjk at the copy.

The movies don't play.

kjk plays the games' movies by itself, so you do not need to install anything else. This includes high-resolution movies from mods.

If a movie still does not play, update kjk to the latest version. Then check that the game's Movies folder has the movie files.

How do I play KOTOR II instead of KOTOR?

Start a new game and choose KOTOR II on the first screen.

Is kjk safe? My antivirus flagged it.

The downloads are not signed, and new unsigned programs often trigger antivirus warnings. kjk's code is public under the MIT licence, and the downloads are built by public GitHub workflows. Anyone can read the code or build kjk themselves.

Only download kjk from this site, from GitHub or from the kjk page on Nexus Mods. Nexus sometimes holds the Windows download for a check. When that happens, use GitHub.

Does it run on Mac, Linux and the Steam Deck?

Yes. kjk runs on Windows, on Macs with Apple silicon and on Linux. Mac downloads sometimes come out a little later than the others, because GitHub's Mac build machines are often busy.

On the Steam Deck, add kjk to Steam as a non-Steam game and start it from Game Mode. Steam then hands kjk the Deck's controls as a gamepad.

On Linux, if kjk does not find KOTOR II, set the KJK_KOTOR2 environment variable to the game's steamassets folder.

There is no Android version. The controls need a keyboard and mouse or a gamepad.

Can Steam count my play time?

Yes. Open the launcher's Settings page and copy the line under "Steam play time". In Steam, open KOTOR's or KOTOR II's Properties and paste the line into Launch options. When you press Play in Steam, Steam starts kjk through the launcher and counts the time.

Co-op

How do I play with friends?

Up to three players can play together. The host plays the main character and keeps the save. Each friend plays a companion.

  • To host, choose Host on the main menu, then start a new game or load a save.
  • To join, choose Join on the main menu, type the host's IP address, then your name.

Everyone needs the same version of kjk and the same mods.

My friend can't connect to me.

On the same network, join with the host's local IP address. The host can find it by running ipconfig in a command window.

Over the internet, the host must open UDP port 29170 on their router and allow kjk through their firewall. Friends then join with the host's public IP address.

Some networks can't open ports. Then use a virtual network such as Tailscale, Radmin VPN or ZeroTier, and join with the host's address on that network. If it still fails, try swapping who hosts.

It says my game files do not match the host's.

kjk checks that every player has the same game files, because different files make the game run differently for each player. Make sure every player has the same kjk version and the same mods, with identical Override and modules folders.

What do the other players control?

Each friend picks a companion in the co-op lobby before the game starts. If no companion is free, the friend controls a small remote droid instead.

The party shares one inventory. Each player levels up the companion they play, and any player can start a conversation. A main character for every player is planned for a later version.

In co-op, Z takes a break, Y says you are ready to leave an area, and N follows the next party member while you watch.

Can I join through Steam instead of an IP address?

Not in the downloads. Joining through Steam needs Steam's networking, which kjk's downloads do not include. Use an IP address or a virtual network such as Tailscale.

Combat and controls

Why do I deal no damage, or die in one hit?

KOTOR's character sheet still sets the numbers behind every swing and shot. Your level, attributes, feats and equipment decide your chance to hit and how much damage you deal. Dual-wielding without the two-weapon feats, or a character with a low level, does much less damage.

In version 0.20 and later, the Combat options have damage multipliers for the party and for enemies, from 10% to 800%. Use them to make fights easier or harder.

How do I block?

A lit lightsaber blocks blows and deflects blaster bolts by itself, as in Jedi Academy. Jedi Defense decides how often a character deflects.

Under the Advanced combat rules, hold the right mouse button to block with a melee weapon. A block that starts just before the blow lands is a perfect block. On a controller, hold LB to block, and press the right trigger while holding LB for a perfect block.

The bars above characters show their block points, not their health. You can turn them off under Options, Gameplay, Sabers.

How do the saber styles and melee feats work?

Press L to change the saber style. With one lightsaber, Flurry is the fast style, Critical Strike is the medium style and Power Attack is the strong style. Two lightsabers and double-bladed lightsabers have the fast and medium styles only, and their melee feats work as passive bonuses.

Press T to change the feat attack of the weapon in your hands. This works with guns, two blades, double-bladed lightsabers, fists and stun batons.

How do I use Force powers, medpacs and grenades?

Hold F to open the power wheel. The wheel lists your Force powers, medpacs, stims and grenades. On a controller, hold RB.

The action bar has ten slots. Keys 1 to 9 use the first nine slots, and key 0 uses the tenth. To fill the bar, press K to open the Abilities page and press the Action bar button.

Every key and button can be changed under Options, Gameplay, Keymap.

Why is one of my Force powers greyed out?

Armor blocks some Force powers, as in the original games. Take off the armor, or wear Jedi robes, to use them.

My companions don't follow me.

Solo mode is probably on. In solo mode, companions stay where they stand instead of following you. Press the Solo mode key, Q by default, to turn it off.

Can I pause the game?

Yes. Press Z to pause. In co-op, Z asks every player for a break.

How do I pick up a mine?

Your character needs at least one rank in Demolitions. Walk close to the mine and point at it. Turn the mouse wheel to choose the action, then press E.

Mods and Movie Duels

How do I install KOTOR mods?

Install mods into the original game folder, in the usual way. Copy them into Override, or run their installer, such as TSLPatcher or HoloPatcher. For KOTOR II you can also subscribe to mods on the Steam Workshop.

Nothing is installed into kjk itself. kjk reads the game's files when it starts, so it picks up new mods by itself.

Which mods work?

Most mods work. Players have reported these as working:

  • texture, model, armor and robe mods
  • the KOTOR 1 Community Patch
  • KOTOR 1 Restoration and the KOTOR II restored content mod (TSLRCM)
  • HQ Skyboxes II and High Quality Blasters

These do not work, or only partly:

  • Interface mods. Only KOTOR II interface mods are expected to work. Widescreen and larger-font mods are not needed, because kjk already supports any screen size.
  • Jedi Academy mods, apart from saber blade mods and Movie Duels.
  • Animation mods, because kjk uses Jedi Academy's animations.

The Discord has a mod-support forum with one post per mod. Search it before you try a mod.

What is Movie Duels, and do I need it?

Movie Duels is a Jedi Academy mod with lightsaber stances from the films. You don't need it. kjk's Advanced combat rules are kjk's own and work without Movie Duels. Movie Duels only adds its stances and its lightsaber hilts.

To use it, install Movie Duels into Jedi Academy, so that its MD folder sits next to Jedi Academy's base folder. Do not put it next to kjk. Then turn the stances on under Options, Gameplay, Sabers.

Movie Battles II is a different mod and is not supported.

Does ReShade work?

Yes, on Windows, with launcher 0.3.1 or newer. ReShade 5.8.0 and 6.8.0 both work. You set ReShade up once, and it stays set up when kjk updates.

  1. Run ReShade's setup.
  2. When it asks for a game, choose kjk-launcher.exe, not kjk.exe.
  3. When it asks for the rendering API, choose Vulkan. kjk draws with Vulkan, so the other choices do nothing.
  4. Start kjk with the launcher's Play button.

If you set ReShade up on kjk.exe instead, ReShade 6 stops kjk from starting.

Tools that change the original game's program do not work, because kjk does not run that program.

Performance and graphics

The game runs slowly.

Try these steps in order:

  1. Update your graphics driver. kjk uses Vulkan, which needs a recent driver.
  2. Set the shadows to Low or Off in the graphics options.
  3. Lower the effects quality.

kjk needs a graphics card that supports Vulkan. Without one it falls back to drawing on the processor, which is far too slow to play.

If a place stays slow, press F12 there and post the bug report. Large fights are not fully optimised yet.

How do I play in fullscreen, and what if the game won't start after I change the screen size?

Press Alt + Enter to switch between borderless fullscreen and a window.

If kjk no longer starts after you changed the screen size, open kjk's settings.json. On Windows it is in %APPDATA%\kjk. Set "display.mode" to "window" and "display.size" to "". Don't delete the whole file, because it also holds your game folders and key bindings.

Does kjk have DLSS, FSR or HDR?

kjk has TAA anti-aliasing. DLSS is in the code, but it will only be in the downloads once NVIDIA approves it. Until then, DLSS works only in a build made from source. FSR is not supported. HDR is available when enhanced lighting is on.

Saves and updates

How do I update kjk?

The launcher checks for a new version each time it opens and tells you when one is out. Click the update button to install it. The launcher backs up your saves and settings before a new version starts for the first time.

To try pre-releases, turn them on in the launcher's settings.

Do updates break my saves?

No. Saves carry over to new versions. Saves from the original KOTOR games can't be loaded.

Can I spawn items or change my character?

There is no cheat console. kjk comes with a save editor that can add items and change your character, such as their head and their companions' influence.

Older KOTOR save editors, such as KSE, can't read kjk's saves.

Bugs and problems

How do I report a bug?

Press F12 in the game the moment something goes wrong. kjk saves a bug report zip with a screenshot. Post the zip in the bug-reports forum on the Discord, one post per bug, or attach it to a GitHub issue. Please list the mods you use.

If the game crashes, attach the files from kjk's logs folder. On Windows it is in %APPDATA%\kjk\logs.

Known problems are listed in KNOWN-ISSUES.md.

The screen goes black, or a story scene gets stuck.

This is usually a mod conflict. Test the scene with a clean install of the game. A black screen at the Taris swoop race usually comes from a partly removed KOTOR 1 Restoration. Install the mod fully again, or use a clean install of KOTOR.

If it happens with a clean install, press F12 and report it.

The project

How playable is it?

KOTOR plays from the Endar Spire to the credits, with some problems along the way. KOTOR II plays from Peragus to the credits, but far fewer players have tested it. Cutscenes are rebuilt rather than played back, so some still look wrong.

Will kjk cost money?

No. kjk is free. Its code is released under the MIT licence, so anyone can read it, change it and build on it.

Is kjk the same as other KOTOR remake projects?

Probably not. kjk is its own engine, not a mod for Jedi Academy or for KOTOR. Some other projects are built on kjk's open code, but they are made by other people.

Was kjk made with AI?

Yes. kjk's code was written with heavy help from AI coding tools. kjk uses no AI-made art. Every model, texture and sound comes from your own copies of the games.
