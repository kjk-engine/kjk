# The approved tests (`crates/approved_tests`)

The only permanent tests (AGENT.md), each a scenario the owner approved by
name (2026-09-30; `script_vm`, `weapon_holdings`, `gui_layouts` and
`ui_loot` 2026-10-01; the three `dialogue_…` and `ragdoll_physics`
2026-10-02; `blank_cells_name_nothing` proposed 2026-10-02; `use_actions`
`use_scripts`, `use_walk` and `saves_round_trip` 2026-10-02; `beast_strikes`
asked for 2026-10-03, and `fists_brawl` with its `humanoid_punches` in
place of `humanoid_does_not`; the I31 co-op ten, from `guests_drive_companions` to
`save_copy_parts`, 2026-10-03, as were `saves_round_trip`'s refusals by
`Snapshot::in_combat` and `gui_layouts`'s changed and added checks;
`net_core`, `net_codec` and `net_sessions` 2026-10-03, the network's own
probes, which had never run outside `kjk net`; `switch_player_character`
asked for 2026-10-03; `fight_through_a_hold` proposed 2026-10-03;
`galaxy_and_end` and `gui_layouts`'s `galaxy_map` and `credits` checks
asked for 2026-10-04; `pazaak`, `item_uses` and `feats` approved
2026-10-04; `traps_lifecycle` and `stealth_spot` 2026-10-04; `bash_doors` and
`map_fog` asked for 2026-10-05, with bashing and the fog of war; the nine
grass, weather and emitter tests from `surface_probes` to `particle_limits`
proposed 2026-10-07 and 08, awaiting the owner; `scene_mode` approved
2026-10-17; `old_saves_load` and `bump_files` proposed 2026-10-28, awaiting
the owner; `coop_data_check` approved 2026-10-30; `stale_stamps_load`
proposed 2026-10-30, awaiting the owner);

## Running
```bash
cargo test --release -p approved_tests               # what CI runs; no Bevy, ~3 min cold
cargo test --release -p approved_tests -- --nocapture   # with the measured numbers
cargo test -p approved_tests --features rig timeline_jolt_ceilings   # the rig too
cargo test -p approved_tests --features rig weapon_holdings
```
CI (`ci.yml`, Linux, pushes to main and pull requests) runs them after
publish-check and fmt, with clippy in a job beside them; `manual.yml` runs
them on Windows and macOS on the 1st of each month and when started by hand.

## Re-pinning
- The sim hash, when the sim changes on purpose (docs/SIM.md): never by
  hand on a branch. Add `bumps/<branch>.toml` with `sim = "why"` (a
  snapshot bump moves it too); `sim_determinism` then checks every way
  agrees but leaves the hash to the merge, whose pin workflow writes it
  into `ci.yml` and `manual.yml` (`bumps/README.md`).
- A jolt ceiling, when an animation change moves a peak on purpose: read
  the new peaks (`--nocapture` prints them), check each sits on a cue or a
  landing (docs/SKELETON.md), and set the ceiling a little above.
- A movement number is JA's and does not move; a failure is a bug.
- An approved case a design moves on purpose (scene mode moved
  `dialogue_coop`'s `one_seat_as_before`, and the sim hash 05f0167e →
  07a086ca → 8febc32c): the case is changed to the design's rule in the
  commit that moves it, its row here says so with the date, and the change
  is listed old → new for the owner, who may have it reverted.
