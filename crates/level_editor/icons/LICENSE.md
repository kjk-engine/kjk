# The marker icons

The icons in this folder are from line-md by Vjacheslav Trushkin
(https://github.com/cyberalien/line-md), under the MIT License below. Each
is the last frame of the icon's animation, drawn in white. The level editor
tints each one in the colour of the kind of thing it marks.
